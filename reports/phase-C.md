## 过程分提案

P1 以 75% 胜负、25% 过程合成主分。过程由塔分、累计卸货、有效伤害按 0.4 / 0.3 / 0.3 合成。按成员等权、各级等权计分，4,000 次地图簇抽样保留双座；SE 为零的级对不进入中位数。

## 命令与材料

| 命令 | 输出 |
| --- | --- |
| `grade` | JSON：`headline`、`headlineOutcomeOnly`、`headlineProcess`、各级胜平负、区间、固定锚 Elo。框架错误重试后仍失败时，两种主分为 `null`；逐局原件留在评测机。 |
| `scrimmage` | `results.json`、`results.md`、每 25 回合快照 `turns.csv`、最多三份败局完整回放；不输出过程指标。公开包已实测 12 局。 |
| `calibrate --mode adjacent` | `results.json`：逐级比较和总判定。迁移后在评测机运行 56 对、每对 24 局，对照 ±50 Elo。 |
| `bench` | 保留原测速方法，以评测机实测冻结本机锁。`league` 延后。 |
