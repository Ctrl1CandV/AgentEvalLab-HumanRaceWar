# B 阶段候选败局复核与 r16 准备

复核了七份候选的 1,680 局已有开发对局。1,014 局败局中，889 局在回合上限因塔分落后而结束。r16 先用配对消融验证建塔或争塔机制是否改善塔分和胜负，作者交付后再做独立 dev 筛查。

| 败局的判定依据 | 局数 |
| --- | ---: |
| 达到回合上限，塔分落后 | 889 |
| 基地被毁 | 123 |
| 达到回合上限，塔分相同，资源交存较少 | 2 |
| 合计 | 1,014 |

889 局塔分败局中，有 171 局的资源交存不低于对手。终局记录能说明胜负如何判定，仍需通过消融确认哪项策略能改善结果。

独立审查确认，第 6、7 条在现行计分下可以同时满足。保留其余已测结果时，最有利的四个替换位置也不足以让第 6 条过线。第 7 条的 M-balanced 对 L6 即使只换一名且新成员全胜，整级得分也至少为 0.1146。r16 的正式候选判断需要核算整级和全阶梯的降分空间。冻结名单和门槛继续用于比较，holdout 尚未启动。
