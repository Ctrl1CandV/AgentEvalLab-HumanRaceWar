# HumanRaceWar 天花板实验预登记

当前冻结版 B 的未通过判定已经结案。本实验由 Fable 与 astra 各自设计，评测使用已登记的 dev 对阵。[退场审查与实验任务](../inbox/2026-11-21-ceiling-experiment.md)

## 启动

两条作者线收到相同的经验材料和两份可见 astra 参照。材料包含败局原因聚合、同对手风格指标、r14–r18 的经验、两份可见参照的逐级成绩。评测侧核对了四份封存提交的字节标识。两份留出参照原件与最终评测输入留存于评测侧。

Fable 使用已有作者工作区，另为 astra 导出一个无 Git 历史、凭据和评测目录的新作者工作区。两边在工作区的制度边界内自测，并经同一入口串行使用 arena。astra 启动提示曾指向仓库里的预算投影路径。已确认导出工作区根目录的 budget-lock-jobs6.json 与该投影逐字节相同，并将正确位置告知会话。有效回合限额为 60 ms。

## 登记的赛程与判定

每份候选通过标准离线 check 后打 3,040 局。四份 astra 参照与 L11 三份参照各用 80 张 dev 图、双座、两组互换的身份种子，共各 320 局。十份公开诊断对手各用预先登记的 40 张 dev 子集、双座、同一组身份种子，共各 80 局。对局使用原 graph 固定锁、jobs 6 和 bwrap。每局以胜 1、和 0.5、负 0 计分。

一份候选须对两份留出的平均得分至少为 85%，对两份可见参照各至少为 90%，才能判成功。留出均值为 65% 至 85% 时判部分。留出均值达到 85% 但未同时通过可见参照门槛时，也走部分分支。低于 65% 走失败分支。两份可见均至少 90% 且可见均值比留出高超过 15 个百分点时，记录专门克制信号。L11 和公开挑战者成绩供参考。

两条线每线至多两轮。首轮每线最多三份候选，第二轮先为每条未达标线保留一个完整评测名额，再按剩余名额定额。30,000 局总上限可以覆盖至多九份全赛程候选。短检查失败单独登记。赛程形状与阈值边界已通过零对局检查。
