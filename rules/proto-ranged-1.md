# 前哨原型：远程兵种

`proto-ranged-1` 是独立原型，不包含能量激活塔分。除下列差异外，沿用[标准规则与协议](rules.md)；地图、原有兵种、自动塔分和胜负规则不变。

| 新能力 | 规则 |
| --- | --- |
| `UNLOCK R` | 花 160 能量解锁远程兵，整局最多成功一次。开局未解锁。它和 `SPAWN` 共用基地生产槽，不能同回合造单位；`FIRE` 仍可用。回合开始时须有足够能量，第 3 步生产结算时扣款；若基地已被摧毁、对局已结束，不扣款。 |
| `SPAWN R x y` | 已解锁的一方可以按原生产规则花 100 能量制造远程兵。最早可在解锁后的下一回合生产，远程兵计入原人口上限。 |
| 远程兵 | 生命 60，伤害 15，可用 `ATTACK id x y` 攻击曼哈顿距离 1 或 2 的敌方单位、塔或基地。距离 2 时，两点之间至少要有一条经空地地形的两步正交路径；中间单位不阻挡，墙、基地、矿和塔基阻挡。 |

远程兵按原移动规则移动，不能采矿、卸货或建塔。攻击仍在移动前按同一个回合起点同时结算；远程兵阵亡当回合的攻击仍生效。基地射击和回复照旧。兵种价格让远程兵比近战更贵、生命更少，而解锁要放弃一回合的造兵机会，供本次单一配置检验，不是平衡结论。

## 协议和运行

- 开局为 `RULESET proto-ranged-1`，新增参数见 [`proto-ranged-1.json`](proto-ranged-1.json)。每回合在 `PLAYER` 之后发两行 `TECH player R 0/1`，表示各方是否已解锁。成功解锁会产生公开事件 `EVENT UNLOCKED player R`。`UNIT` 中远程兵类型为 `R`，已有字段格式不变。
- 未解锁就生产远程兵记 `TECH_LOCKED`，已解锁后再次解锁记 `ALREADY_UNLOCKED`，距离 2 没有空地路径记 `RANGE_BLOCKED`。第一次语法完整的 `SPAWN` 或 `UNLOCK R` 占用本方生产槽，错行处理沿用原协议。
- 本原型只通过 `--prototype-rules rules/proto-ranged-1.json` 开启。两项原型不能混用；不加选项仍是 `standard-1`。公开固定近战对手可使用原 zoo，筛选中的固定解锁和自适应解锁使用单独的探针源，不修改冻结 zoo。
