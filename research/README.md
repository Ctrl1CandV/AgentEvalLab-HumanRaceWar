## 硬规则

- **隐藏内容永远不进本目录或其他公开文件。** 隐藏阶梯 bot 不点名、不描述风格以外的细节、不写弱点；dev、calibration、grading、holdout 地图不描述；涉及隐藏成员的对局、回放和逐局表一律不放进来。本目录只引用仓库里已经公开的聚合数字。
- **遵守 `AGENTS.md` 和 DESIGN 第 16 节。** 每次 clone 后执行 `git config core.hooksPath .githooks`；不用 `--no-verify`；回放、逐局表和结果库不上传 GitHub，按 `docs/REPOSITORY.md` 执行。
- **不碰凭据。** 不读取、打印、复制或写入任何凭据、令牌、认证配置。
- **只引用核实过的文献。** 新条目照 [literature.md](literature.md) 的格式写，核不到的标"未核实"。
- **跑东西之前先看 STATUS。** 机器上可能正在做计时敏感的测量；HRW 的对局、编译、测速都要错峰，不抢锁（`AGENTS.md`"运行与证据"）。
- **本仓库是公开的。** 推送之后这里的规划人人可见，包括模型开发方。写下一版阶梯的计划时，不写会削弱它的细节（见 [paper-plans.md](paper-plans.md) 第 6 节）。
