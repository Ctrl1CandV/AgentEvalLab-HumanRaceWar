# 能量激活原型：公开图筛选预登记

本轮按 [11 月 25 日 CA 裁定](../inbox/2026-11-25-ceiling-result-review.md#四原型任务综合会话一段做完中途不交审)执行。筛选要看的是：在同一套行动策略下，局势自适应的买分办法能不能稳定胜过调好的固定办法。它不等于「加大作者预算就会显著变强」；后一个问题只在过筛后用新标准提交和加力作者测试。

- **规则与策略。** [规则](../rules/proto-energy-1.md)固定价格 2、4、8。所有探针以原 M-balanced 为底，只换激活模块：全部激活、不早于固定回合且保留固定余额、自适应。网格为开始回合 `1/45/90/135/180/225/270` × 储备 `0/80/160/320`，共 28 格。自适应在赛前固定，按积分差、剩余回合、平滑后卸货量、塔数和受威胁程度算储备，不从确认集回调参数。
- **拆分。** 四类图各把每种尺寸的第一张放入调参集（编号 01–05），第二张放入确认集（编号 06–10），各 20 张。每配对每图四局：双座，各跑身份种子 `17/29` 与 `29/17`。地图是统计单位，不把四局当四张图。
- **调参。** 每个价格把各固定策略只对「全买版」打满调参集。取胜负得分最高者。若最高分并列，先取边界格（不能把并列包装成内部最优），再按开始回合、储备升序取首格。同价内两个参数都不在边界才满足网格条件。
- **确认。** 每价用同一确认集测三条边：自适应对最优固定，自适应和最优固定各对全买版。主要读数是直接对战的自适应得分减固定得分（即 `2 × 自适应得分 − 1`）。同图按四局平均，再按地图整簇抽样 4,000 次、种子 `4219`，报告 95% 区间。另报告双方对同一个全买版的同图同座得分差，只作诊断。
- **过筛。** 同一价格须同时满足内部最优、主差值区间下限严格大于 0、四类图中至少三类点估计为正。三档区间是名义区间，只作原型筛选。多档过筛时选区间下限最高的档，仍同则选较低价格。全不过就按裁定改做一次远程兵种原型，不增加能量价格或重复筛选。
- **读数。** 另报塔分决胜比例、终局塔分差分布、到第 150 回合塔分落后的一方最终取胜比例，以及每回合 CPU 用时。回合未到、当时平分分别列出，不视为未翻盘。只按胜 1、平 0.5、负 0 计局分；运行器判负照计，框架失败只按标准路径重试，未完成或无法核验不得出筛选结论。

三档合计调参 6,720 局、确认 720 局，共 7,440 局。只用原 graph 机器锁、jobs 6、离线 bwrap。赛前固定代码与地图摘要，核验全部完成结果及确认集回放；编译不启动宿主程序，原始失败和所有对局留在评测工作区。没有 calibration、grading 或最终 holdout，原冻结结果不重算、不替换。
