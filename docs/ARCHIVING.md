# 每轮只读归档与总账

按2026-11-13新分工T2执行；归档工具只处理文件字节，不运行bot/引擎，不是新的计分控制器。用户允许先用于本轮归档，下次CA审查一并核公开代码。

## 一次性存量基线

T1结束后，按旧方法最后一次遍历private，核旧登记保全并写`private/HIDDEN.sha256`。该文件随后只读，作为**当时存量快照**初始化`private/ledger.jsonl`，不再随每个维护动作刷新。旧目录设为只读，父级保留创建新轮目录的权限。

baseline不声称覆盖后来新增的文件；总账、锁和持续追加的ladder-notes属于明确的控制元数据。旧笔记的既有前缀不能改写。历史lane/窗口只存档，不再控制写入。

## 新的一轮

一次运行批或作者交付使用新的专属目录，完成全部输出后：

```sh
.venv/bin/python tools/archive_round.py seal private/<本轮目录> --round <唯一轮次ID>
.venv/bin/python tools/archive_round.py verify --round <唯一轮次ID>
.venv/bin/python tools/archive_round.py chain
```

工具拒绝链接、特殊文件、越界路径、自包含清单和重复轮次ID；逐文件哈希后写出`private/manifests/<ID>.json`，移除轮目录写权限，最后在ledger追加一行并fsync。行内含轮次、清单路径/摘要、文件数、字节数、前一行摘要。链摘要使用不含换行的规范JSON字节。旧行不覆盖；中断/半行必须停报，不自动修复账本。

归档之后不再向原目录追加文件或改变字节。运行中的目录不能seal；失败输出、技术停和被拒版本同样保留。补充证据另建目录、另记一行，不把事后记录说成当场日志。

平时只核新轮文件和总账链条，不重算所有旧文件。`verify`检查某一新轮的文件集合、摘要、字节数和只读权限；里程碑和B交审前，再由维护任务核全存量基线、全部轮清单和控制元数据追加关系。SHA链和只读模式是协作保护，不是防同UID恶意篡改的签名或OS隔离。

## 发布保护

pre-commit仍检查本地目录、体积、凭据类路径和逐局材料。`tools/publication.py`一次读取旧HIDDEN及总账绑定的新轮清单，拒绝将相同隐藏字节提交到公开路径；清单变化或账本断链时拒绝提交。新工具自身的纯测试不启动bot或编译器。

公开只放每轮一页报告及聚合；逐文件清单、总账、回放、逐局表和原始日志都只留本机。维护/LSP/hashseed细节写日志，不灌入STATUS或每轮报告。局部CPU、墙钟与完整会话成本分开，未知不编造。
