# 前哨：第二阶段（优化）

用新会话优化现有 `bot/`，尽量提高它在 Outpost 中的表现。先读 `README.md`、`rules.md`、自己的 `NOTES.md` 和 `scrimmage/results.json`。可查看 `turns.csv` 和附带的公开练习赛回放，从第一阶段冻结的 `bot/` 继续。上限是 8M token、3 小时，任一用尽即冻结。保持离线，编译和运行只走 bwrap 与宿主提供的固定时限锁；不测速，不用 plain。短检查单独执行，开发只用公开开发图。

评分看对固定阶梯的对局表现，胜负最重要，细节不公开。阶梯 1.0.0 有 13 级：低段含公开基础对手，Z-random、Z-miner、Z-eco、Z-harass 分别代表随机、采矿、经济、骚扰；中段有经济和控制等启发式策略（公开锚点 M-balanced）；高段含进攻、经济、控制等策略。

只使用当前工作区和本会话产生的信息，不访问旧会话、外部记忆、其他目录和互联网。完成后冻结 `bot/`、`NOTES.md`、`usage.json` 和文件 `SHA256SUMS`（不含清单自己）；实际 token 无法取得就写 `null`。交付后停止开发和自测，不推送。
