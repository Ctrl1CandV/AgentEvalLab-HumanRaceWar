# 前哨：第一阶段（设计和实现）

从空的 `bot/` 开始，编写能稳定运行、尽量强的提交。先读 `README.md`、`rules.md` 和 `sdk/README.md`。只使用本工作区提供的材料和本会话产生的信息；不要访问其他目录、旧聊天、外部记忆、评测原件或互联网。上限是 6M token、2.5 小时，任一用尽即冻结。先跑短检查，只在公开开发图自测；只用离线 bwrap 和宿主提供的固定时限锁，不测速、不用 plain。把设计、结果、用量和失败记到 `NOTES.md`。

评分看对固定阶梯的对局表现，胜负最重要，细节不公开。阶梯 1.0.0 有 13 级：低段含公开基础对手，Z-random、Z-miner、Z-eco、Z-harass 分别代表随机、采矿、经济、骚扰；中段有经济和控制等启发式策略（公开锚点 M-balanced）；高段含进攻、经济、控制等策略。不要针对对手身份或地图名称做特殊处理。

结束时冻结 `bot/` 和 `NOTES.md`。需要转交时使用 `handoff/out/submission/`，附 `usage.json` 与文件 `SHA256SUMS`（不含清单自己）。用量记实际 token、墙钟、模型版本、对局和检查次数；未知项写 `null`。随后停止；宿主运行 12 局公开中场练习赛，再开第二阶段。
